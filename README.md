# 📚 Instructions for Setting Up the Ohstem Programming Environment

## 📝 Step-by-Step Guide

### 1️⃣ Step 1: Access the Ohstem Programming Environment
- Open the following link to use the Ohstem programming platform:  
  [https://app.ohstem.vn/](https://app.ohstem.vn/)

### 2️⃣ Step 2: Import Required Libraries
- Import the necessary libraries as shown in the **Import_Library** image provided.

### 3️⃣ Step 3: Import the Cookie File
- Import the **cookie file** to enable programming and code uploading to the **Yolobit** device.
